# IoP技術者コミュニティ フィジカルAI編 — Gemini Robotics ER 2 ハンズオン

IoP技術者コミュニティ R8年度 第4回講座（フィジカルAI編）の Colab ハンズオン教材です。

## 使い方

下のリンクを開き、上から順にセルを実行してください（左の鍵アイコンに `GEMINI_API_KEY` の登録が必要です）。

**[▶ Colab でノートブックを開く](https://colab.research.google.com/github/ptk-y-nakahira/iop-er2-handson/blob/main/er2_hands_on_ja.ipynb?hl=ja)**

## 内容

- `er2_hands_on_ja.ipynb` — Google 公式 [gemini_robotics_er.ipynb](https://github.com/google-gemini/robotics-samples/blob/main/Getting%20Started/gemini_robotics_er.ipynb)（Apache-2.0）の説明文を日本語化し、講座オリジナルの発展（Google Drive の写真読み込み・グラフ読解）を追加したものです。コードは公式のままです。
- `demo-box-wide.jpg` — 発展編で使うデモ環境（ミニ温室2台＋制御装置）の写真
- `chart_realboard.png` — 発展編で使う、温室 A/B の実測データ（1分間隔・丸1日分。A=ファン制御あり / B=ファン封鎖の対照区）を RealBoard® で表示したダッシュボード画面
- `harvest_usda.webm` — 発展編で使う実写映像（USDA 撮影・パブリックドメイン・9.9秒。飼料ハーベスタの排出シーン）
